# Package templates

`harness.py prepare` downloads and verifies the Pick'N'Mix Multi Overlays With Box V1 archive, then extracts only these ignored local inputs:

- `Template_MultiOverlay.package`
- `Template_OverlayBox.package`
- `NoFaceOverlay.package`

The pinned URL, archive hash, and individual package hashes are recorded in `manifest.json`. Do not commit or redistribute the downloaded package files. Review the upstream terms again before any distribution beyond this private prototype.
